## Project Focus
EduLense is a cross-platform educational productivity application designed with a left-handed-first user interface. The application prioritizes ergonomic layout, dominant-hand comfort, intuitive control placement, and gesture optimization tailored for left-handed users. It aims to reduce friction and fatigue commonly experienced with right-hand-biased applications.

## Project Overview
EduLense is a Flutter application focused on delivering a personalized learning experience.
