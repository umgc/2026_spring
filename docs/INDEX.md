# EduLense Documentation

EduLense is a cross-platform learning workspace delivered through shared product concepts and platform-specific implementations:

- Root web app in `src/`
- Standalone web package in `edulence_web/`
- Electron desktop app in `edulence_desktop/`
- Expo React Native app in `edulence_rn/`
- Flutter app in `edulence/`

## Start Here

1. Read [Repository Overview](../README.md) for the high-level project summary.
2. Use [Architecture Overview](./ARCHITECTURE.md) to understand how the platforms fit together.
3. Follow [Setup Guide](./SETUP.md) for local development on each platform.
4. Use [Deployment Guide](./DEPLOYMENT.md) for release packaging and delivery.
